## 2 

Abbiamo un sistema che tiene traccia dei punteggi di un giocatore.
all inizio ha come punteggi : 10, 20, 30, 40

Richieste : il giocatore ottiene un nuovo punteggio: 50; 
            aggiungilo alla lista
            successivamente, l ultimo punteggio viene annullato, quindi, va rimosso.
            stampa l array aggiornato.


# 3 

Stiamo gestendo un sistema che gestisce due liste di frutta, provenienti da diversi fornitori.

    Hai 2 array.

    Primo fornitore : mela, banana, uva, ciliegia.
    Secondo fornitore :  mango, ananas, arancia.

Richieste : unisci le due liste in un unica lista di frutta.
            verifica se "banana" è presente nella lista.
            trova la posizione di "ananas" all interno dell array.
            trasforma la lista finale in una stringa separata da una virgola.
            stampa tutti i risultati ottenuti,
            stampa la lunghezza dell array.
